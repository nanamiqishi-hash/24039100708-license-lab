# 课程资料整理小工具 (Course Material Organizer)

## 一句话简介
本项目是一个基于 Python 开发的命令行辅助小工具，旨在帮助同学高效整理按周次和日期分类的课程学习资料。

## 项目状态
**开发中**：当前处于设计与初期开发阶段，核心的 Python 脚本正在编写中，暂未实现完整的文件自动归档与重命名功能，暂未提供可执行安装包。

## 安装获取
当前为设计开发阶段，暂无发布安装包。未来计划提供源码运行方式：需要本地安装 Python 3.8+ 环境，克隆仓库后运行 `python main.py`。

## 使用说明
目前暂无完整的可运行程序。你可以通过阅读本 README 了解工具的预期功能：
1. 预期支持按“课程名称/周次/日期”自动创建文件夹。
2. 预期支持将下载的杂乱文件自动移动并规范命名。
